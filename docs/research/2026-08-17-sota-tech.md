# SOTA Techniques (2024–2026) for Feedback Metrics — condensed

*Research agent report, 2026-08-17. Part of the feedback-metrics survey. Full URLs in original.*

## Tracking (tool-tip kinematics)
- 2D tip kinematics READY; tissue-point research-grade; monocular metric-3D at microscope scale = hype (keep kinematics 2D, limbus-normalized).
- **Track-On2 (MIT)**: >30fps @256 pts, 0.5GB VRAM, online/causal, beats CoTracker3 — top pick (CoTracker3 is CC-BY-NC). TAPNext/TAPNext++ (Apache-2.0) with occlusion re-detection; JAX friction.
- SAM2.1 = NOT a tip tracker (point prompts drift; mask 93.1% vs 42.4% IoU); right role = mask temporal smoothing/QA.
- Caution: MICCAI STIR 2024 — plain MFT optical flow beat all learned trackers on surgical tissue; validate on ~50 labeled clips before shipping numbers. Blueprint: mask-skeleton seeded queries, Savitzky-Golay derivatives, 4-12Hz tremor band, limbus-normalized (~11.7mm); <2GB, ~5-10 GPU-min/video.

## Foundation models
- **OVFM (Nature BME 2026)** — ophthalmic VideoMAE on 1.1M surgical clips w/ skill + complication heads, prospectively validated wet-lab; highest ceiling; LICENSE UNSPECIFIED (resolve first).
- OphCLIP weights unreleased; SurgVLP-family lap-domain + NC; EndoFM/GSViT/SurgeNet wrong domain; SurgVISTA ND-licensed. Nothing beats our supervised phase model — value is motion features/new heads, not phase.
- Methodology to copy: SAIS bias audits + TWIX explanation supervision; JHU cross-site degradation → local calibration set before deploying learned scores.

## LLM/VLM feedback
- Raw-video VLM feedback PREMATURE (GPT-4o phase acc 36%, triplets <2%).
- **Structured metrics → LLM narrative = ready + the field's converged architecture** (structured conditioning doubled clinically-admissible generations 21→42%; ICEMS RCT: automated feedback ES 0.332; GPT-4o feedback helpful 86.8% in radiology). No one has done cataract-kinematics→LLM feedback — open gap. Validation bar: blinded expert admissibility panel.
- Local: Qwen3-VL-32B (Apache-2.0) on 2×A40 TP=2; 8B text-only fits one A40, seconds/report. Middle path: metrics + phase-localized keyframes into VLM.

## Other
- Depth: ordinal flags only (DA3Mono/VDA-Small Apache); metric 3D = no. Gaze prediction unvalidated; use CatSkill-style behavioral proxies instead (AUC 0.865, reimplementable in 1-2 wks; only new piece = Purkinje-1 blob detector).
- Diffusion expert counterfactuals = hype + medicolegal risk; substitute RETRIEVAL (expert clip of same phase) + cohort trajectory envelopes (median±IQR tip-path heatmap).
- **Conformal prediction on skill scores = highest-value cheap win** (days, no GPU): split conformal intervals from cohort, suppress feedback when wide. Nobody has published conformal skill scores.
- Video-based PCR anticipation: unpublished anywhere — paper-worthy, not a feature.
